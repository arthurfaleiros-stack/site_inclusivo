# Casa Aberta – Site Inclusivo

Projeto com HTML, CSS e JavaScript.

## Como abrir
Abra a pasta no VS Code e rode `index.html` com a extensão Live Server (ou dê dois cliques no arquivo).

## Estrutura
- index.html: as 6 páginas (Início, Sobre, Cursos e eventos, Mídia, Acessibilidade, Contato)
- style.css: estilos, temas de contraste e responsividade
- script.js: navegação, zoom, contraste, leitura em voz alta, filtros, players e formulário

## Para completar
- Trocar a animação por um <video> com <track kind="captions">
- Adicionar um <audio> real com transcrição
- Incluir o framework exigido (ex.: React) e/ou um assistente de IA
